# Harvard Resume Builder

A private, browser-based resume editor with a live Harvard-style preview.

## Features

- Real-time resume preview
- Contact, summary, education, experience, projects, skills, and certification sections
- Local browser autosave
- Direct PDF export
- Desktop split view and mobile Edit/Preview tabs

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Validation

```bash
npm run lint
npm run build
```
